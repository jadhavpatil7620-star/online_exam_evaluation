# Online Assessment & Evaluation Portal (OAEP)

Online Assessment & Evaluation Portal (OAEP) is a web-based examination management system developed using Python, Django, MySQL, HTML, CSS, and Bootstrap 5. The application enables students to register, log in, select subjects, attend online examinations, and view their results instantly.

The system includes a dedicated Admin Panel that allows administrators to manage students, subjects, questions, examinations, and results through complete CRUD operations. The portal supports session-based authentication, question navigation, automated score calculation, result generation, and secure data management.

## Features

* Student Registration and Login
* Session-Based Authentication
* Subject-Wise Online Examinations
* Dynamic Question Management
* Previous and Next Question Navigation
* Automated Score Calculation
* Instant Result Generation
* Student Result History
* Admin Dashboard
* Student Management (CRUD)
* Question Management (CRUD)
* Responsive User Interface using Bootstrap 5
* MySQL Database Integration

## Technologies Used

* Python
* Django
* MySQL
* HTML5
* CSS3
* Bootstrap 5

## Project Goal

The primary objective of OAEP is to provide a digital platform for conducting online assessments efficiently while reducing manual effort in examination management, evaluation, and result processing.
